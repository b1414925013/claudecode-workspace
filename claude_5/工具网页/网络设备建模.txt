# 角色
你是一名资深前端 3D 可视化工程师，精通 Babylon.js 和电信网络资源建模。

# 核心任务
创建一个单文件 HTML 应用，对电信运营商的网络资源层级进行 3D 建模与可视化。
层级固定为 7 层（从根到叶）：
  网络 → 业务 → 小区 → 站点机房(房子) → 网元设备 → 单板 → 端口

# 数据模型规范
- 用 JS 对象树表达层级，每个节点含：id, name, type, status(normal/warning/alarm/offline), attrs(属性字典), children[]
- 数据量：1 个网络根节点 + 3 个业务 + 7 个小区 + 7 个站点 + 每站点 2~3 个网元 + 每网元 2~4 块单板 + 每单板 0~8 个端口，全树约 300+ 节点
- 用模板生成器批量产生网元/单板/端口（如 BOARD_TEMPLATES、NE_META），保证命名真实感：
  - 网元：eNodeB(华为DBS3900)、PTN汇聚传输(中兴ZXCTN 950)、动环监控ECC800
  - 单板：UMPT主控板、UBBP基带板、UFLP光接口板、UPEU电源板、EG16电口板、LSVF光口板
  - 端口：光口 槽位/0/序号（10GE SFP+）、电口 槽位/0/序号（GE），含收光功率属性
  - 小区：含 ECI、PCI、频段(Band3/41/5)、带宽、方向角、下倾角、覆盖区域
  - 站点：含站点编号、地址、经纬度、机房类型
- 告警分布：约 5% 端口设为 alarm（收光功率过低 LOS），约 5% 设为 warning（误码率偏高），少量网元设 warning；告警节点不能全部藏在最深折叠层

# 3D 可视化规范
- 引擎：Babylon.js（本地文件优先加载，失败回退 jsDelivr CDN 并带 SRI 校验）
- 布局：径向树布局（radial tree）——每层一个 Y 高度平面（层间距约 7 单位），子节点在该层按角度均分分布在以根为圆心的递增半径圆周上
- 每层用不同几何形状区分：
  - 网络/业务：发光球体
  - 小区：六棱柱（蜂窝意象）
  - 站点机房：立方体 + 四棱锥屋顶（"房子"造型）
  - 网元设备：瘦高长方体（机柜）
  - 单板：扁平横放长方体
  - 端口：小圆柱
- 节点颜色按层级区分（金/琥珀/青/蓝/紫/绿/橙），告警节点覆盖为红/黄状态色
- 父子节点间用二次贝塞尔曲线连接，半透明发光蓝灰色
- 背景：深色(#070b14) + 雾化 + 粒子悬浮光点 + 底部半透明圆盘数据底座 + 光环装饰
- 发光效果：GlowLayer，节点材质带 emissive
- 告警节点：红色 scale 脉冲动画（render loop 中 sin 驱动）
- 标签：HTML overlay（非 3D 文字），每帧用 Vector3.Project 将世界坐标投影到屏幕更新位置；含层级色点 + 名称；有后代告警的节点加红色脉冲角标

# 交互功能清单（全部必须实现）
1. 左键单击节点：选中 + 展开/收起子层级（有子节点时），右侧滑出详情面板
2. 详情面板：面包屑路径、类型图标、状态徽章、属性表、直属子节点数/后代节点数统计
3. 左键拖拽空白：旋转相机；滚轮：缩放；右键拖拽：平移
4. 点击与拖拽区分：pointerdown 记录坐标，pointerup 时位移 < 10px 才算点击
5. 悬停节点：手型光标 + 节点 emissive 增强 2.2 倍 + 标签加粗
6. 搜索框：模糊匹配节点名/id，点击结果自动展开祖先路径 + 相机缓动聚焦
7. 工具栏按钮：展开全部、收起全部、自动旋转、重置视角、全屏
8. 告警面板：顶部红色告警按钮（带计数）+ 底部状态栏告警数字均可点击；列表面板展示所有非 normal 节点（名称/类型/状态/告警原因），点击自动定位
9. 底部状态栏：节点总量、当前可见、层级深度、告警数
10. 左侧图例：7 层颜色说明 + 4 种状态色

# 相机与视角
- ArcRotateCamera，target 对准可见节点的加权重心（约 y=-20），初始 radius 约 58
- 重置视角按钮用缓动动画回到初始 target 和 radius
- 限制 beta 范围（0.32~1.52）防止穿地或俯视过度

# UI 设计规范
- 深色运维大屏风格，面板用 rgba(10,17,29,.86) + 细边框 + backdrop-filter
- 字体：系统字体栈（微软雅黑/苹方），不依赖外部 web font
- 所有 UI 元素 z-index 高于 canvas，标签 pointer-events:none
- 响应式：窄屏隐藏图例和提示文字

# 技术约束（硬要求）
- 单文件 index.html，原生 HTML/CSS/JS，无 React/Vue/构建工具，不用 type="module"
- canvas CSS 必须用 position:fixed;top:0;left:0;width:100vw;height:100vh（不要用 inset:0，会导致 canvas 保持默认 300×150）
- 拾取坐标必须用 scene.pointerX / scene.pointerY（不要用 ev.pointerX，高 DPR 屏会偏移导致点不中）
- 节点 mesh 必须设 metadata.nodeId，scene.pick 的 predicate 只拾取带 nodeId 的 mesh
- 展开/收起通过 dispose 旧动态节点 + 重建实现，rebuild 时清空 hover 状态
- Babylon.js 库文件与 index.html 同目录，script 先加载本地 babylon.min.js，typeof BABYLON==="undefined" 时 document.write 回退 CDN
- 初始默认展开到网元层（单板/端口折叠），避免首屏节点过多

# 交付
- 输出完整可运行的 index.html
- 附带 babylon.min.js（同目录）
- 说明文件路径和打开方式
